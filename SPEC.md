## Engine contract
Each turn moves one reel by one step through Cherry, Star, Bell, Lightning, Diamond. Up advances the index, bringing the symbol below into the centre. Cherry Club is independent. Electric Night links 1→2 and 2→3; 3 is independent. Diamond Room links 1→2, 2→3, 3→1. Coupled reels move in the same direction. There is no random input or automated reel spin.

Levels have fixed starts/targets, generated by stable integer formulas. Breadth-first search over 125 states returns the true shortest path using precisely the same transition function as gameplay. Each limit is optimum + 3. Three stars at optimum, two at optimum + 1, one for any other within-limit completion. Best is the lowest move count. Undo reverses the last transition and refunds exactly one move. Hint/check cost no moves. At the limit controls stop; Check resolves success or shows the retry/solution screen. Undo remains available. Unlimited restarts preserve personal bests.

## Storage, errors and offline
Versioned Codable state in Application Support/NeonReels/progress-v1.json, atomically written after every move or setting. Stores per-level and daily attempts including undo stacks, bests and preferences. Loading state on launch. Bad saves are not overwritten; a retry or explicit reset is available. Reset backs up before clearing. Storage errors remain visible while the live session continues. Everything is available offline; there is no server, live data, analytics, login, purchase, advertising or remote secret.
